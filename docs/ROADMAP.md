# Roadmapa

## ETAP 1 — Architektura i szkielet
Repo, dokumentacja, mapa AI, kontrakty, zasady bezpieczeństwa.

## ETAP 2 — Core + Identity + Authorization
User, Role, Group, Membership, permissions, podstawowy CalendarEvent i testy izolacji.

## ETAP 3 — Groups + Calendar + Sessions
Grupy, harmonogramy, sesje, kalendarz, karta sesji.

## ETAP 4 — Assignments + Media
Prace domowe, terminy, submissions, PDF/audio/video, YouTube/Vimeo, Google Drive adapter.

## ETAP 5 — Discussions + Attendance + Tests + Ops
Czat, dyskusje sesji, obecność, testy, backup, deployment.

Później: dashboard terapeuty, integracja z Dzienniczkiem, kolejne moduły, powiadomienia, hardening.
