# TERAPIA Platform

Platforma do organizacji terapii grupowej: grupy, kalendarz, sesje, materiały, prace domowe, dyskusje i obecność.

KALENDARZ → SESJA → TEMAT / MATERIAŁY / PRACA DOMOWA / DYSKUSJA / OBECNOŚĆ

Prywatny Dzienniczek samoobserwacji pozostaje prywatny. Członkostwo w grupie nie daje automatycznie dostępu do prywatnych wpisów.

## Etapy
1. Architektura i szkielet
2. Core + Identity + Authorization
3. Groups + Calendar + Sessions
4. Assignments + Media
5. Discussions + Attendance + Tests + Ops

Workflow: ANALIZA → PLAN → ZMIANA → TEST → RAPORT → HANDOFF
